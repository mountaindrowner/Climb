# The Climb: theme editor values

*Edit Theme, on the live page. Every colour is from the game's own palette.*

| Control | Value | From |
|---|---|---|
| BG | `#181425` | the game's ink (the night sky) |
| BG2 | `#262b44` | deep blue (the HUD's panels) |
| BG2 Alpha | 0.92 | so the page background just shows through |
| Text | `#c0cbdc` | pale (the game's body text). 8.5 : 1 on BG2 |
| Link | `#feae34` | the flame. 7.5 : 1 on BG2 |
| Buttons | `#a22633` | his scarf's red. White on it is 7.3 : 1 |
| Headers | `#fff2d0` | the title's cream. 12.5 : 1 on BG2 |

| Font | Value |
|---|---|
| Header font | Pixelify Sans (the game's own menu font) |
| Page font | Atkinson Hyperlegible (plain and easy to read on dark) |

| Image | File | Settings |
|---|---|---|
| Banner | `images/banner.png` | 960 x 300, transparent. It replaces the page title |
| Background | `images/page-bg.png` | Repeat: both ways. Align: centre. Fixed: off |
| Embed background | `images/embed-bg.png` | 1280 x 720, the title screen's mountain |
