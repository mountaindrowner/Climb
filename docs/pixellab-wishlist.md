# What to make with PixelLab

A standing list of art to generate when there is budget (decision 0.10 in `docs/roadmap.md`: spend what there is,
keep $0.20 back). Add to it whenever something is drawn in code as a stand-in, or waits for credit. Strike an item
through, with the build, when it is made.

How: `python3 tools/pixellab.py` (its header lists the commands); swings follow the recipe in `docs/side.md`. Check
the balance first (`python3 tools/pixellab.py balance`). An animation with its light map has cost about 2 to 3 cents.

Balance on 2026-11-16: **$3.43**, generations 0 (the monthly generations refill in a few days).
